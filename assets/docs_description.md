[たーけクラウドシステム](https://scratch.mit.edu/studios/33110478/) （☁システム）ver.5 に対応した、公式 APIv2 です。
☁システムに関する情報の取得や、管理チームへのバグ報告など、様々な機能を提供しています！

APIへのリクエスト方法など、詳しい内容は [公式ドキュメント](https://docs.takechi.cloud/api/) に掲載しています。

## APIサーバーの稼働方法
APIサーバーは、管理者の PC ではなく外部サービスで稼働しています。
そのため、さまざまなアクシデントによる稼働停止が起こりにくい設計になっています！

## 注意事項
- APIを悪用した・試みた場合は、アクセス制限を行ったり、全体での提供を終了したりすることがあります。
